# Job Application Bot

An automated job application system that searches and applies for Software Engineer and Java Developer positions on LinkedIn and Naukri.

## Features
- Automated job searching on LinkedIn and Naukri
- Focus on entry-level and internship positions
- Job matching based on profile
- Automated application filling
- Detailed job analysis and reporting
